# Yuan (yuan1521913)

I build small, verifiable engineering products and show the evidence in public:

- [code-audit-cli](https://github.com/yuan1521913/code-audit-cli) - a local-first code security quick scan for dangerous patterns like SQL concatenation, unsafe deserialization, command execution and reflected HTML. It runs on your machine, prints a readable report, and never uploads your code.
- [raft-kv](https://github.com/yuan1521913/raft-kv) - a 3-node Raft sharded key-value store with real failover, persistence and migration evidence you can inspect before deciding whether the source package fits your backend portfolio.

Both public repositories are evidence walls, not empty advertisements: rules, sample output, architecture notes and honest boundaries are all public. The full source code is delivered under a commercial source license, not published here.

## Why I show this on GitHub

A demo that "should work" is weak evidence. A three-node cluster that survived a stopped leader, and a scan report that points at the exact risky line, are evidence you can actually look at. This profile is where those two projects keep their public receipts.
